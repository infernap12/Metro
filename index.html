One-time setup

The upstream GTFS API doesn't send CORS headers, so this page needs a proxy. The free option is a Cloudflare Worker (100k req/day, no card).

  1. Open dash.cloudflare.com and sign up if needed.
  2. Workers & Pages → Create → Worker.
  3. Paste the contents of worker/gtfs-proxy.js, then Deploy.
  4. Copy the *.workers.dev URL into the field below.
